# VoxTexto V2.0

A numeração foi simplificada: a versão anterior v1.2.0 passa a ser identificada como V1.0; esta atualização, antes identificada no código como v1.2.1, passa a ser V2.0.

Atualização do aplicativo Windows, anteriormente chamado Transcrição em Texto, com a mesma interface apresentada no portfólio.

- Suporte a arquivos OGG, incluindo Vorbis e Opus.
- Seleção de arquivos centralizada, com os formatos abaixo do botão.
- Reconhecimento de OGG na fila, no histórico e nas estatísticas.
- Nome VoxTexto na interface e nas informações de versão do aplicativo.
- Correção do nome do instalador no build automático e validação das versões do código, executável e instalador.

Baixe `TranscricaoEmTexto-Setup-V2.0.exe` para Windows 10/11 de 64 bits.

Formatos aceitos: MP3, MP4, WAV, M4A e OGG. A transcrição usa o Whisper small e ocorre localmente; uma conexão pode ser necessária na primeira execução para baixar o modelo.

O identificador de instalação foi mantido para permitir a atualização da versão anterior. Os dados do usuário permanecem armazenados separadamente dos arquivos do aplicativo.
